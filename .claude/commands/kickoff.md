Start-of-session ritual for Jinsula:

1. Read `KICKOFF.md` at the repo root.
2. Load ONLY the files its "Load in" / reading-list section points to for the likely topic — do not re-explore the repo, re-read SPEC.md wholesale, or re-derive project context (CLAUDE.md is already loaded).
3. Give the user a recap of at most 3 lines: current state, and the candidate topics from KICKOFF.
4. Ask which topic this session is for (or accept one if given in $ARGUMENTS), then confirm whether it's a planning session or a building session before touching any code.

Remember: this is a safety-first medical helper. Sessions are short and single-topic; planning-only unless the user asks to build. Never add logic that computes an insulin dose — see SPEC.md safety principles.
